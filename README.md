# 🦅 URUBU DO PIX™

Site de paródia fictícia, feito para deploy direto na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy

Suba o projeto para GitHub e importe o repositório na Vercel.
A Vercel detecta o Vite automaticamente.

Não há banco de dados nem backend real. O "backend" mostrado na interface é apenas uma simulação visual de inicialização.

## Aviso

Este projeto é uma paródia. Não coleta PIX, não processa pagamentos e não promete retornos financeiros reais.
